# 第 5 章 失业与通货膨胀

<p class="cf-subtitle">失业的衡量与成因、通货膨胀的衡量与成因、菲利普斯曲线</p>

## 5.1 失业的定义与衡量

**失业**：处于法定劳动年龄、具有劳动能力且有工作意愿的劳动者找不到工作岗位的经济现象。

| 人口划分 | 说明 |
| --- | --- |
| 人口 ＝ 劳动年龄人口 ＋ 非劳动年龄人口 | 非劳动年龄人口：小于 16 岁或在专门机构生活、无法工作 |
| 劳动年龄人口 ＝ 劳动力人口 ＋ 非劳动力人口 | 非劳动力人口：主要指在校学生及退休人员 |
| 劳动力人口 ＝ 就业者 ＋ 失业者 | 失业率的分母是劳动力人口，不是总人口 |

| 身份 | 统计口径 |
| --- | --- |
| 就业者 | 调查前一周至少有偿劳动 1 小时，或为家族企业无偿劳动多于 15 小时；或虽未工作但只是临时离开岗位 |
| 失业者 | 调查前一周没有工作，且调查前 4 周曾努力找工作，或正在等待重新获得被解雇的岗位 |

$$
\text{失业率}=\frac{\text{失业人数}}{\text{劳动力人口数}}\times100\%,
\qquad
\text{劳动参与率}=\frac{\text{劳动力人数}}{\text{劳动年龄人口数}}\times100\%
$$

??? note "课件数据摘录"

    - 劳动参与率：中国约 76%，美国 65%，日本 58%，印度 55%。
    - 失业率（%）：

    | 年份 | 1960–98 | 2009 | 2012 | 2020 | 2024 |
    | --- | ---: | ---: | ---: | ---: | ---: |
    | 美国 | 6.0 | 9.3 | 7.8 | 8.1 | 4.1 |
    | 欧盟 | 6.4 | 9.6 | 11.0 | 7.5 | 5.9 |
    | 日本 | 1.9 | 5.1 | 4.2 | 2.8 | 2.5 |

    - 中国城镇登记失业率：2011–2015 年为 4.1%，2020 年 4.24%，2022 年 5.6%，2024 年 5.1%；就业人数从 2011 年的 76196 万人降至 2024 年的 73439 万人（《中国统计年鉴》）。

## 5.2 失业的分类与充分就业

| 类别 | 含义 | 原因／特点 |
| --- | --- | --- |
| **自愿失业** | 有工作机会，但出于种种原因自愿放弃工作 | — |
| 摩擦性失业 | 正常的劳动力周转造成的失业 | 劳动市场信息不完全；规模取决于劳动力流动性、找工作的成本、就业信息渠道 |
| 结构性失业 | 技术或经济结构变化导致所需技能、工作地域变化 | 职业不匹配、地区不匹配 |
| 季节性失业 | 季节性气候变化导致的失业 | 某些行业的生产经营具有季节性 |
| **非自愿失业** | 有劳动能力，愿意接受现行工资水平或工作条件，仍找不到工作 | 又称需求不足性失业或周期性失业；经济衰退时增加，扩张时减少 |

| 概念 | 定义 |
| --- | --- |
| 充分就业 | 经济中不存在非自愿失业，所有失业都是自愿、摩擦性、结构性、季节性失业 |
| 自然失业率 | 充分就业时的失业率 |
| 潜在 GDP（潜在产量） | 经济在充分就业状态下所能生产的 GDP |

充分就业和自然失业率为分析短期波动提供参照。总产出主要取决于劳动投入、资本存量和技术；短期内资本和技术变化不大，总产出主要由就业人数决定。

## 5.3 失业的原因

| 学派 | 核心观点 |
| --- | --- |
| 新古典经济学 | 以**萨伊定律**为核心：供给能创造需求，供求总趋于均衡，不会出现生产过剩；生产者理性，生产销售达到最高水平，实现充分就业。若有失业，只是自愿失业和摩擦性失业，是局部、暂时的失调 |
| 凯恩斯 | 市场经济存在失业的必然性；在摩擦失业、自愿失业之外提出**非自愿失业**，用**有效需求**理论解释 |
| 新凯恩斯主义 | 以不完全竞争、不完全信息为前提，用**工资黏性**解释非自愿失业 |
| 现代货币主义 | **自然失业率**假说；弗里德曼据此否认长期存在失业与通胀的交替关系 |

**凯恩斯的有效需求理论**：有效需求是总供给与总需求达到均衡时的社会总需求。两部门经济中，有效需求由消费需求和投资需求构成。有效需求不足时，均衡产出 $Y_0$ 低于充分就业产出 $Y_f$，对应的就业量 $N_0$ 低于 $N_f$，出现非自愿失业；要实现充分就业，需要总需求从 $AD_0$ 提高到 $AD_f$。

| 有效需求不足的原因 | 机制 |
| --- | --- |
| 边际消费倾向递减 → 消费不足 | 收入增加时边际消费倾向递减；若消费减少的同时投资相应扩大（储蓄转化为投资），不一定造成有效需求不足 |
| 资本（投资）边际效率递减 → 投资可能不足 | 投资规模扩大，投资边际效率递减；只要利率能不断下降，投资仍可增加 |
| 流动性陷阱 → 利率不能无限降低 | 投机性货币需求与利率反向变化；存在流动性陷阱时，货币再增加利率也降不下去；投资边际效率接近利率时，厂商不愿投资 |

总需求的决定：消费需求取决于收入水平和边际消费倾向；投资需求取决于投资边际效率和利率；利率由流动偏好（货币需求）和货币政策（货币供给）决定。

**新凯恩斯主义的工资黏性理论**：

| 理论 | 要点 |
| --- | --- |
| 劳动工资合同论 | 工会力量使合同附加工资随生活费上涨而增加、衰退时不降的条款；合同期相对固定，减缓工资调整 |
| 隐含合同论 | 雇主与雇员达成工资相对固定、不随经济波动调整的默契 |
| 局内人-局外人理论 | 企业向新、老雇员支付相同工资，解决老员工不愿培训新员工、老员工被别的企业"挖走"的问题 |
| 效率工资理论 | 支付高于市场出清水平的工资可提高劳动生产率、获得更多利润；企业不愿率先降薪，以免降低积极性、流失最好的雇员 |

**现代货币主义**：自然失业率指没有货币因素干扰时，劳动市场和商品市场自发供求力量作用下、处于均衡状态的失业率。政府增加货币刺激就业，劳动者在没有预见到实际收入下降时愿意增加劳动供给；但长期中货币量增加引起价格上涨，实际工资不变甚至下降，劳动者不再多提供劳动，失业没有减少，物价却持续上涨。

## 5.4 失业的影响与奥肯定律

| 层面 | 影响 |
| --- | --- |
| 个人和家庭 | 物质和精神的负面影响：家庭收入、身心健康、家庭声望 |
| 社会 | 影响社会稳定，失业率高时尤甚 |
| 经济 | 增加经济运行成本、带来产出损失、影响整个社会的信心 |

**奥肯定律**：经济周期中，失业与产出反向变动。美国 1947–1960 年 55 个季度的数据显示，失业率每高于自然失业率 1 个百分点，实际产出低于潜在产出 3 个百分点：

$$
\frac{Y-Y_f}{Y_f}=-\alpha\,(u-u^*)
$$

$\alpha=3$ 是经验数值，不同国家、不同时期不完全相同。

**重要结论**：GDP 没有达到充分就业水平时，实际 GDP 必须保持与潜在 GDP 同样的增长速度，才能避免失业率上升。相关研究表明，中国 GDP 每增长 1 个百分点约对应 200 万新增就业，这是强调"保 5"的原因。

??? example "用奥肯定律估算产出缺口"

    设 $\alpha=3$，自然失业率 $u^*=5\%$，实际失业率 $u=7\%$：

    $$
    \frac{Y-Y_f}{Y_f}=-3\times(7\%-5\%)=-6\%
    $$

    实际产出比潜在产出低 6%。（数值为说明用的假设。）

## 5.5 通货膨胀的定义与衡量

| 概念 | 定义 |
| --- | --- |
| 通货膨胀 | 一定时期内价格水平**普遍而持续**地上升：是物价总水平而非一两种商品的上涨；持续一段时期而非短暂上涨；达到一定幅度 |
| 通货紧缩 | 价格水平普遍而持续地下降 |
| 物价稳定 | 价格水平既不上升也不下降 |

**物价指数**：

$$
PI_t=\frac{\sum P_{it}Q_{it}}{\sum P_{i0}Q_{it}}\times100
$$

$P$ 为第 $i$ 种商品价格，$Q$ 为数量，$t$ 为报告期（现期），$0$ 为基期。

$$
\text{GDP 平减指数}=\frac{\text{名义 GDP}}{\text{实际 GDP}}\times100,
\qquad
CPI=\frac{\text{现期价格下"篮子"总额}}{\text{基期价格下"篮子"总额}}\times100\%
$$

| | GDP 平减指数 | CPI |
| --- | --- | --- |
| 衡量范围 | 国内**生产**的所有产品与服务 | 消费者**购买**的产品与服务 |
| 企业、政府购买的产品 | 反映 | 不反映 |
| 进口品 | 不反映（不是 GDP 的一部分） | 反映（若在篮子中） |
| 共同点 | 都衡量一般价格水平，提供价格变动的信息；选用哪个取决于研究目的和数据可得性 | |

我国 CPI 基期每五年轮换，2016 年 1 月起以 2015 年为基期（前三轮为 2000、2005、2010 年）。篮子包括食品烟酒、衣着、居住、生活用品及服务、交通和通信、教育文化和娱乐、医疗保健、其他用品和服务等 8 大类、262 个基本分类；数据来自全国 31 个省（区、市）500 个市县、6.3 万家价格调查点，"定人、定点、定时"采集。

**通货膨胀率**：

$$
\pi_t=\frac{P_t-P_{t-1}}{P_{t-1}}\times100\%
$$

$P$ 既可用 GDP 平减指数，也可用 CPI。

??? note "课件数据与案例摘录"

    - 美国 CPI 同比在 2022 年 6 月达 9.1% 的高点，2023 年 9 月回落到 3.7%。
    - 1920 年代初德国：一份报纸从 1921 年的 0.3 马克两年后涨到 7000 万马克。
    - 苏联解体后：1992 年物价上涨 2500%，1991–1995 年上涨近 5000 倍。
    - 津巴布韦 2009 年 1 月通胀率高达 2.31 亿%，发行面额 100 万亿的钞票。
    - 委内瑞拉 2018 年 11 月通胀飙升至 150000%。
    - **痛苦指数**（Misery Index，奥肯提出）＝失业率＋通货膨胀率。

## 5.6 通货膨胀的类型

| 分类标准 | 类型 | 特征 |
| --- | --- | --- |
| 价格上升程度 | 温和（爬行）的通货膨胀 | 通胀率低，一般在 10% 以内，较稳定 |
| | 加速（奔驰）的通货膨胀 | 通胀率较高，一般在两位数以上，且持续加剧 |
| | 恶性（超速）的通货膨胀 | 货币贬值达天文数字，每月通胀率达 50% 以上 |
| 人们的预料程度 | 预期的通货膨胀 | 公众能准确预期物价上涨率 |
| | 未预期的通货膨胀 | 人们没想到会涨价，或涨幅超出预料 |
| 商品价格变动的差别 | 平衡的通货膨胀 | 各种商品（包括要素）价格按相同幅度上升 |
| | 非平衡的通货膨胀 | 各种商品价格上升幅度不完全相同 |
| 表现形式 | 公开性的通货膨胀 | 完全通过物价上涨表现 |
| | 隐蔽性的通货膨胀 | 物价上涨没有完全反映在官方物价指数中 |
| | 抑制性的通货膨胀 | 有通胀压力，但价格被政府管制无法上涨，表面物价不涨而商品普遍短缺 |

## 5.7 通货膨胀的成因

<picture id="ch05-inflation-causes">
  <source media="(max-width: 640px)" srcset="../figures/ch05-inflation-causes-mobile.svg">
  <img src="figures/ch05-inflation-causes.svg" class="cf-fig" alt="左：AS 不变，AD 由 AD₁ 右移至 AD₃，价格持续上升，接近充分就业时产出增加越来越少；右：AD 不变，AS 由 AS₁ 左移至 AS₃，价格上升而产出下降" width="600" height="250">
</picture>

| 类型 | 含义 | 原因／子类型 |
| --- | --- | --- |
| **需求拉上型** | 总需求超过总供给引起的物价普遍而持续上涨 | 财政政策、货币政策、国际市场需求变动等；AD 右移，越接近充分就业，越表现为价格上涨 |
| **成本推动型** | 供给方面生产成本提高引起的物价普遍而持续上涨 | 工资推动型：不完全竞争的劳动市场造成过高工资；利润推动型：垄断、寡头企业利用市场势力谋取过高利润；进口型：重要进口物资涨价使本国生产成本上升；出口型：出口迅速扩张使出口部门边际成本上升（与出口增加引起的需求拉动型不同） |
| **结构型** | 经济结构性因素变化引起的物价上涨 | 需求转移型：需求结构变化而生产要素不能及时转移，需求增加部门涨价、减少部门价格不降；生产率差异型：生产率提高慢的部门要求工资向提高快的部门看齐；斯堪的纳维亚小国型：大国通胀经国际贸易传到小国开放部门，再带动非开放部门；进出口不平衡型 |
| **混合推动型** | 需求拉上与成本推动共同作用 | AD 与 AS 交替移动，价格螺旋上升 |

**货币主义的解释**：货币是影响总需求的主要因素。

$$
M\cdot V=P\cdot Y
$$

货币流通速度 $V$ 由货币制度和技术因素决定，产出 $Y$ 取决于技术和要素投入，短期内都不变。结论：通货膨胀是货币供给增加的结果；中央银行保持货币供给稳定，物价水平也就稳定。

??? note "课件资料：国际原油与铁矿石价格"

    - 原油：20 世纪 70 年代两次石油危机推动油价暴涨（1981 年初最高 39 美元/桶）；1983–2003 年基本在 30 美元以下；2003–2008 年快速上升，2008 年 7 月 14 日创 147.27 美元/桶历史高点；2009–2014 年大幅波动，2014 年 6 月起从 110 美元跌至 30 美元。
    - 铁矿石：2004–2011 年中国进口价格从不足 30 美元/吨涨到 180 美元；2015 年进口量增长 2.2%，价格下跌 39%，约为 2011 年峰值的 1/4。

## 5.8 通货膨胀的效应与治理

**惯性**：通胀发展通常是螺旋式上升，原因可能是预期，或需求拉上与成本推动共同作用。多数人预期下期通胀与上期相同时，预期会变成现实，因为工资、利率、租金等名义变量与价格之间互为因果。现实中多数通胀兼有需求和供给两方面因素。

**社会成本**：

| 成本 | 含义 |
| --- | --- |
| 鞋底成本 | 持有货币的成本增加：人们更频繁地跑银行，银行也要多雇职员 |
| 菜单成本 | 厂商调整价格的成本：研究确定新价格、重印价目表、更换价格标签等 |
| 价格"噪声" | 掩盖价格所传递供求信息的真实性，降低市场效率 |

**对收入分配的影响**（促进论、促退论、中性论之争）：

- 不利于靠固定收入生活的阶层：工薪阶层、公共雇员、领取退休金和救济金的人群。
- 有利于债务人、不利于债权人：实际利率＝名义利率－通胀率。
- 有利于政府、不利于公众：产品价格提高，厂商上交的税收增加；名义工资提高，所得税增加（"通货膨胀税"）。

**对财产的影响**：财产净值＝资产价值－债务价值。

| 项目 | 通胀时的变化 |
| --- | --- |
| 价格可变的资产：土地、房屋等实物资产，股票等金融资产 | 价格大体随通胀率变动，实际价值基本不变 |
| 金额固定的资产：现金、存款、买进的债券 | 本息金额固定，实际价值下降 |
| 债务：贷款、分期付款、私人借款 | 本息金额固定，实际负担下降 |

??? example "物价上涨 1 倍后的实际财产净值"

    | 项目 | 居民 A 前 | A 后 | 居民 B 前 | B 后 | 居民 C 前 | C 后 |
    | --- | ---: | ---: | ---: | ---: | ---: | ---: |
    | 价格可变的资产 | 2000 | 2000 | 20000 | 20000 | 10000 | 10000 |
    | 金额固定的资产 | 1000 | 500 | 10000 | 5000 | 20000 | 10000 |
    | 债务 | 4000 | 2000 | 0 | 0 | 0 | 0 |
    | 财产净值 | −1000 | +500 | +30000 | +25000 | +30000 | +20000 |

    价格可变资产的实际值不变，金额固定的资产和债务实际值减半。结论：金额固定的资产比例越高，损失越大（居民 C）；债务越多，得益越大（居民 A）。

**对产出的影响**：可能增加生产和就业。未预期时，物价上涨快于货币工资，生产者利润增加而增产；预期到时，生产者不能增加利润，但会刺激现期消费。前提：通胀是需求拉动的（成本推动型会在涨价的同时减少产量和就业）、社会有闲置资源、通胀是温和的。

| 治理措施 | 作用 |
| --- | --- |
| 紧缩性财政政策与货币政策 | 抑制总需求，抑制物价上涨（AD 左移） |
| 技术创新（转型升级、增长方式转变） | 推动 AS 右移 |
| 指数化政策 | 使收入、债券等随物价指数调整，保持购买力 |
| 个人的预防和对抗 | 形成预期、调整资产结构，承担鞋底成本与菜单成本等 |

??? example "养老金的购买力"

    每年通胀 5%，20 年后同样名义金额的购买力：

    $$
    \frac{1}{1.05^{20}}\approx37.7\%
    $$

    课件给出约 35%，与按 $(1-5\%)^{20}\approx35.8\%$ 近似计算一致。投资于指数化债券则购买力不受通胀影响。

## 5.9 菲利普斯曲线

**原始形式（失业-工资）**：1958 年菲利普斯根据英国 1861–1957 年数据，发现**失业率与货币工资变化率反向变动**。由于货币工资变动与通胀密切相关，萨缪尔森和索洛把它改为表示失业与通胀此消彼长的关系。

**修正形式（失业-物价）**：AD 由 $AD_1$ 右移到 $AD_2$，价格从 $P_1$ 升到 $P_2$、产出从 $Y_1$ 升到 $Y_2$；产出增加意味着失业下降，于是通胀率上升对应失业率下降。

$$
\pi=-a\,(u-u^*)
$$

**政策含义**：政策制定者可以选择不同的失业率与通胀率组合，用高通胀换低失业，或用高失业换低通胀（**相机抉择**）。由奥肯定律，增长与失业反向；由菲利普斯曲线，失业与通胀反向；可推得增长与通胀正向变动。

**附加预期的菲利普斯曲线**：**短期菲利普斯曲线**是预期通胀率不变时，通胀率与失业率的关系（"短期"指人们根据通胀调整预期所需的时间）。

$$
\pi-\pi^e=-a\,(u-u^*)
\quad\Longleftrightarrow\quad
\pi=\pi^e-a\,(u-u^*)
$$

| 性质 | 含义 |
| --- | --- |
| 预期通胀率变动 1 单位 | 实际通胀率同向变动 1 单位，短期曲线整体上下移动 |
| $\pi=\pi^e$ 时 | 实际失业率等于自然失业率：短期曲线在预期通胀率水平上与 $u^*$ 相交 |
| 短期 | 预期通胀低于实际通胀时，失业与通胀仍有交替关系，扩张性政策可以减少失业 |

**长期菲利普斯曲线**：长期中工人根据实际情况不断调整预期，预期与实际一致时会要求提高名义工资以保持实际工资，较高的通胀不再能减少失业。长期菲利普斯曲线是一条在 $u^*$ 处的**垂直线**，失业与通胀不存在替换关系，失业率处于自然失业率。

## 5.10 通货紧缩与滞胀

**通货紧缩**：一般价格水平普遍而持续地下降。

| 方面 | 内容 |
| --- | --- |
| 主要特征 | 物价连续下降；伴随产量下降、市场萎缩、企业利润减少、生产投资不足、失业增加、收入下降、增长乏力；货币供给量持续下降 |
| 历史 | 1929–1933 年大萧条，1930–1933 年通缩率分别为 −2.3%、−9%、−9.9%、−5.1%；自 1880 年以来美、德、日 CPI 低于 0 的月份分别为 259、279、230 个，美国 1950 年以来仅 25 个月，发生概率不足 3%；通缩多是重大历史事件后的全球性现象 |
| 消费与投资 | 消费者延后消费，打击当前需求；投资回收期产品价格下跌，回报率下降，遏制投资 |
| 就业 | 企业开工不足、生产下降，失业率明显上升、收入减少 |
| 进出口 | 需求不振，进出口大幅减少 |
| 资产价格 | 资产价格大幅下跌，消费削减、总需求降低；金融机构资产质量下降，可能破产，破坏金融体系 |
| 治理 | 比通胀更难治理：调整与优化产业结构；综合运用各项政策，刺激投资、消费、出口 |

**滞胀**：生产停滞、失业增加与物价水平居高不下同时并存。

| 原因 | 机制 |
| --- | --- |
| 菲利普斯曲线整体右移 | 实际因素：劳动力数量和构成变化、工作转换频率变化、科技进步等使自然失业率上升；预期因素：通胀预期纳入经济行为。同一失业率对应更高通胀 |
| 供给冲击 | 总供给曲线左移：$SAS_1$ 移到 $SAS_2$，价格从 $P_1$ 升到 $P_2$，产出从 $Y_1$ 降到 $Y_2$ |
| 供给学派的看法 | 美国滞胀是凯恩斯主义扩张性政策的结果：扩张性财政政策提高社会福利（如失业救济），降低失业成本，增加失业人数，却不一定带来产量增长；扩张性货币政策导致较高通胀 |

**政策困境**：用紧缩性货币政策或财政政策对付通胀，经济萎缩会加深；用放松银根或赤字支出对付衰退，通胀又会加剧。

## 5.11 公式速查与自测

| 用途 | 公式 |
| --- | --- |
| 失业率 | 失业人数／劳动力人口数 × 100% |
| 劳动参与率 | 劳动力人数／劳动年龄人口数 × 100% |
| 奥肯定律 | $(Y-Y_f)/Y_f=-\alpha(u-u^*)$，经验值 $\alpha\approx3$ |
| GDP 平减指数 | 名义 GDP／实际 GDP × 100 |
| CPI | 现期价格篮子总额／基期价格篮子总额 × 100% |
| 通货膨胀率 | $\pi_t=(P_t-P_{t-1})/P_{t-1}\times100\%$ |
| 交易方程 | $MV=PY$ |
| 实际利率 | 名义利率－通货膨胀率 |
| 附加预期的菲利普斯曲线 | $\pi=\pi^e-a(u-u^*)$ |

1. 失业率的分母是什么？在校学生是否计入失业者？
2. 摩擦性、结构性、周期性失业各由什么引起？哪类失业存在时不算充分就业？
3. 凯恩斯认为有效需求不足的三个原因是什么？
4. 奥肯定律的"重要结论"是什么？
5. GDP 平减指数与 CPI 有哪些区别？
6. 需求拉上型与成本推动型通胀在 AD-AS 图中有什么不同？
7. 通货膨胀对债务人、债权人和固定收入者分别有什么影响？
8. 为什么长期菲利普斯曲线是垂直的？

??? question "自测答案"

    1. 分母是劳动力人口（就业者＋失业者）。在校学生属于非劳动力人口，不计入失业者。
    2. 摩擦性：劳动力正常周转、信息不完全；结构性：技术或经济结构变化造成技能、地域不匹配；周期性（非自愿、需求不足性）：总需求不足，随衰退增加。存在周期性失业时不算充分就业。
    3. 边际消费倾向递减、资本边际效率递减、流动性陷阱（流动性偏好）。
    4. 未达到充分就业时，实际 GDP 必须保持与潜在 GDP 同样的增速，才能避免失业率上升。
    5. 平减指数衡量国内生产的全部产品，含企业和政府购买的产品、不含进口品；CPI 衡量消费者购买的篮子，含进口消费品、不含企业和政府购买。
    6. 需求拉上：AD 右移，价格上升且产出增加（接近 $Y_f$ 后主要是涨价）；成本推动：AS 左移，价格上升而产出下降。
    7. 有利于债务人、不利于债权人（实际利率下降）；靠固定收入生活的阶层实际收入下降。
    8. 长期中人们的预期与实际通胀一致，名义工资随之调整，实际工资和就业不变，失业率回到自然失业率，较高通胀不能降低失业。
