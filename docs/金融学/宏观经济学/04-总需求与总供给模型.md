# 第 4 章 总需求与总供给模型

<p class="cf-subtitle">AD 曲线、AS 曲线与宏观均衡的变动</p>

## 4.1 本章逻辑与符号

凯恩斯交叉图给出 IS，货币需求理论给出 LM；IS-LM 共同均衡在**价格可变**时导出 AD 曲线，劳动市场与生产函数导出 AS 曲线；AD 与 AS 共同决定产出与价格，用来解释宏观经济的短期波动。

| 符号 | 含义 |
| --- | --- |
| $Y,P,r$ | 总产出、价格水平、利率 |
| $M,\ m=M/P$ | 名义货币供给、实际货币供给 |
| $\alpha,\beta,e,d$ | 消费函数常数项、边际消费倾向、投资函数常数项、投资利率系数（同第 3 章） |
| $k,h$ | 交易性、投机性货币需求系数（同第 3 章） |
| $N,W,w=W/P$ | 就业量、名义（货币）工资、实际工资 |
| $Y_f,N_f$ | 充分就业产出、充分就业就业量 |

## 4.2 总需求与 AD 曲线

**总需求**（Aggregate Demand）：一定时期内社会各部门计划购买的产品总量。它取决于消费 $C$、投资 $I$、政府购买 $G$、净出口 $NX$，也取决于价格水平 $P$。

**总需求函数**：产品市场和货币市场同时均衡时，总需求（总产出）$Y$ 与价格水平 $P$ 的对应关系。

**由 IS-LM 推导**：第 3 章令 $P=1$；价格可变时，LM 中的货币供给换成实际货币供给 $M/P$。

$$
\begin{aligned}
\mathrm{IS}&:\ r=\frac{\alpha+e}{d}-\frac{1-\beta}{d}Y\\
\mathrm{LM}&:\ r=-\frac{1}{h}\cdot\frac{M}{P}+\frac{k}{h}Y
\end{aligned}
$$

令两式右边相等，解出 $Y$：

$$
Y=\frac{h(\alpha+e)}{dk+h(1-\beta)}+\frac{d}{dk+h(1-\beta)}\cdot\frac{M}{P}
\quad\text{记作}\quad
Y=\theta_1+\theta_2\frac{M}{P}
$$

**图示推导**：$M$ 不变时，$P$ 上升使 $M/P$ 下降，LM 左移，均衡产出下降；把每个价格对应的均衡产出画到 $P$-$Y$ 平面，就得到向右下方倾斜的 AD。下图用例 4.2 的数据。

**AD 的含义与传导机制**：名义货币供给不变时，AD 表示两市场同时均衡下 $Y$ 与 $P$ 的关系。以价格下降为例：

- 货币市场：$P↓$ → $M/P↑$，原均衡变成货币供大于求 → 货币需求须增加；交易性需求取决于产出，不由货币市场直接决定，故须增加投机性需求 → $r↓$。
- 产品市场：$r↓$ → $I↑$，原均衡变成 $I>S$ → 储蓄须增加，储蓄取决于产出 → $Y↑$。

| 价格与总需求反向变动的机理 | 传导链（以价格上升为例） |
| --- | --- |
| 利率效应 | $P↑$ → 实际货币供给↓ → 投机性货币需求↓ → $r↑$ → $I↓$ → 总需求↓ |
| 财富效应 | $P↑$ → 货币购买力↓ → 人们相对变穷 → $C↓$ → 总需求↓ |
| 税负效应 | $P↑$ → 名义工资↑ → 进入更高税档 → 税负↑ → 可支配收入相对↓ → $C↓$ → 总需求↓ |
| 进出口效应 | $P↑$ → 本国商品竞争力↓ → 出口↓、进口↑ → $NX↓$ → 总需求↓ |

??? example "例 4.1：由 IS、LM 求 AD"

    已知 IS：$r=80-0.4Y$；LM：$r=-\dfrac{4}{5}\cdot\dfrac{M}{P}+0.4Y$；名义货币供给 $M=5000$。求 AD 曲线方程。

    令 IS＝LM：

    $$
    80-0.4Y=-\frac{4}{5}\cdot\frac{M}{P}+0.4Y
    \quad\Rightarrow\quad
    Y=100+\frac{M}{P}
    $$

    代入 $M=5000$：**$Y=100+\dfrac{5000}{P}$**。

## 4.3 AD 曲线的斜率与移动

**斜率**：由 $Y=\theta_1+\theta_2 M/P$ 求导：

$$
\frac{dP}{dY}=-\left[k+(1-\beta)\frac{h}{d}\right]\cdot\frac{P^2}{M}
$$

斜率（绝对值）反映产出对价格变动的敏感程度：**斜率越小，产出对价格越敏感**；斜率越大，产出反应越迟钝。$k,\beta,M$ 短期内稳定，决定斜率的主要因素是 $h$ 和 $d$。

| 参数 | AD 的陡缓 | 机理（以 $P↓$ 为例） |
| --- | --- | --- |
| $h$ 越小 | 越平缓，产出越敏感 | $m↑$ 后须增加 $L_2$，$h$ 小则 $r$ 须大幅下降 → $I$ 大幅增加 → $S$ 与 $Y$ 须大幅增加 |
| $d$ 越大 | 越平缓，产出越敏感 | $r$ 下降时 $I$ 增加的幅度大 → $S$ 与 $Y$ 须大幅增加 |

**移动**：价格不变时，其他因素使 IS 或 LM 移动，AD 水平移动。

| 情形 | IS / LM | AD |
| --- | --- | --- |
| 货币政策：货币供给增加 | IS 不变，LM 右移 | 右移 |
| 财政政策或需求增加 | LM 不变，IS 右移 | 右移 |
| 两者同时 | 都移动 | 按合力移动 |

**区分**：价格变化引起的是沿 AD 移动（它在 IS-LM 图中表现为 LM 移动）；价格以外的因素才使 AD 移动。

| 引起 AD 移动的因素 | 例子 |
| --- | --- |
| 消费需求 | 个人所得税、福利政策、城市化水平 |
| 投资需求 | 企业税收、对市场前景的预期 |
| 政府购买 | 调节宏观经济 |
| 预期 | 收入、利润率、通货膨胀 |
| 世界经济形势 | 汇率、外国收入 |
| 货币供给 | 通过利率影响投资、消费、出口 |

??? example "例 4.2：价格变化与 AD 方程"

    $C=100+0.8Y_d$，$I=150-6r$，$T=50$，$G=40$，$M=150$，$L=0.2Y-4r$。

    **（1）IS**：$Y=C+I+G=100+0.8(Y-50)+150-6r+40$ → $Y=1250-30r$。也可由 $I=S+(T-G)$，$S=-100+0.2(Y-50)$ 得到同一结果。

    **LM**：$L=M/P$。

    | 价格水平 | LM | 均衡 |
    | --- | --- | --- |
    | $P=1$ | $0.2Y-4r=150$ → $Y=750+20r$ | $r=10,\ Y=950$ |
    | $P=1.5$ | $0.2Y-4r=100$ → $Y=500+20r$ | $r=15,\ Y=800$ |

    **（2）$P=1$，$M$ 降为 125**：$Y=625+20r$，与 IS 联立 → $r=12.5,\ Y=875$。

    **（3）AD**：LM 写成 $Y=750/P+20r$，与 $Y=1250-30r$ 消去 $r$：

    $$
    Y=500+\frac{450}{P}
    $$

## 4.4 总供给与 AS 曲线

**总供给**（Aggregate Supply）：一定时期内整个社会的总产量。总产量取决于技术水平、资本存量和劳动投入；技术和资本给定时，取决于劳动投入，而劳动投入与价格水平相关。总供给函数反映 $Y$ 与 $P$ 的关系，其图像是 AS 曲线，可由劳动市场供求曲线与总生产函数推出。

**数理推导**：

| 关系 | 方向 |
| --- | --- |
| 总产出 $Y=f(N)$ | $Y'>0$ |
| 就业量 $N=f(w)$（由劳动市场决定） | 见下 |
| 实际工资 $w=W/P$ | 名义工资不变时，$P↑$ → $w↓$ |
| 总产出 $Y=f(P,w,N)$ | $dY/dP>0$（短期） |

**四象限推导**：（A）劳动市场 $N_d,N_s$ 决定就业 → （B）生产函数 $Y=f(N)$ 把就业换成产出 → （C）45° 线转换坐标 → （D）得到 $P$ 与 $Y$ 的关系。

**AS 的含义**：价格水平影响实际工资，进而影响劳动市场供求和就业量，最终影响总产出。

- 名义工资不变时，实际工资与价格水平成反比；
- 实际工资影响劳动市场供求，供求决定就业量；
- 技术不变时，就业量决定总产出。

**按货币工资能否伸缩分为短期、长期 AS**：

| | 短期 AS | 长期（古典）AS |
| --- | --- | --- |
| 假设 | 凯恩斯货币工资下降刚性：工人有**货币幻觉**，抵制货币工资下降，不抵制价格上涨；货币工资只升不降 | 人们对经济变化有充分认识并能充分调整，货币工资完全伸缩 |
| 形状 | 不同价格水平下形状不同：低价格段近乎水平，中间段向右上倾斜，到 $Y_f$ 后垂直 | 在 $Y_f$ 处垂直 |
| 原因 | 价格较低时货币工资不能再降，实际工资偏高，就业低于 $N_f$ | 价格变动时货币工资同比例变动，实际工资与就业不变，产出始终为 $Y_f$ |

## 4.5 AS 曲线的移动

| 原因 | 机理 | 结果 |
| --- | --- | --- |
| 劳动市场变动 | 劳动需求增加等使 $N_d$ 右移，均衡就业从 $N_f$ 增至 $N_f'$ | $Y_f$ 增至 $Y_f'$，AS 右移 |
| 生产函数变化 | 技术进步使 $Y=f(N)$ 上移为 $Y'=f'(N)$，同样就业产出更多 | AS 右移 |
| 长期总供给增加 | 社会生产能力提高（劳动供给增加、技术进步），同一价格下厂商产量增加 | 对应的短期 AS 同步右移 |

**长期总供给是短期总供给的基础**：$LAS_0$ 移到 $LAS_1$ 时，$SAS_0$ 也移到 $SAS_1$。

??? example "例 4.3：劳动供给形式与 AS 的形状"

    短期生产函数 $Y=14N-0.04N^2$，劳动需求 $N_d=175-12.5(W/P)$。

    **（1）劳动供给 $N_s=70+5(W/P)$**（取决于实际工资）

    | 价格 | 方程 | 均衡 |
    | --- | --- | --- |
    | $P=1$ | $175-12.5W=70+5W$ | $W=6,\ N=100,\ Y=1000$ |
    | $P=1.25$ | $175-10W=70+4W$ | $W=7.5,\ N=100,\ Y=1000$ |

    **（2）劳动供给 $N_s=70+5W$**（只取决于名义工资）

    | 价格 | 方程 | 均衡 |
    | --- | --- | --- |
    | $P=1$ | $175-12.5W=70+5W$ | $N=100,\ W=6,\ W/P=6,\ Y=1000$ |
    | $P=1.25$ | $175-10W=70+5W$ | $N=105,\ W=7,\ W/P=5.6,\ Y=1029$ |

    $Y=14\times105-0.04\times105^2=1470-441=1029$。

    **（3）结论**：劳动供给取决于实际工资时，价格变动不改变实际工资，AS 垂直；劳动者有货币幻觉时，名义工资上升使劳动供给增加、产出增加，AS 向右上倾斜。

## 4.6 AD-AS 均衡与变动

**宏观经济均衡**：AD 与 AS 的交点 $E$ 决定均衡价格 $P_e$ 与均衡产出 $Y_e$。

| 交点位置 | 均衡的市场 |
| --- | --- |
| AS 垂直段（$Y=Y_f$） | 产品、货币、劳动三个市场同时均衡 |
| AS 倾斜段（$Y<Y_f$） | 产品、货币两个市场均衡，劳动市场不均衡（存在失业） |

| 变动 | 原因 | 结果 |
| --- | --- | --- |
| AD 右移 | 消费和投资扩大、政府购买增加、出口增加、货币供给增加等 | $Y↑,P↑$：经济增长与通货膨胀；接近垂直段时主要表现为价格上涨 |
| AD 左移 | 消费和投资萎缩、政府购买减少、出口减少、货币供给减少等 | $Y↓,P↓$：通货紧缩与经济衰退 |
| AS 右移 | 技术创新（还有利用国际资源）；垂直段的位置代表现有资源和技术下的生产可能性边界，右移意味着生产能力增强 | $Y↑,P↓$：技术创新与经济增长 |
| AS 左移 | 劳动力、资源等生产要素价格上升 | $Y↓,P↑$：滞胀 |

## 4.7 三个模型的关系

| | 有效需求决定模型 | IS-LM 模型 | AD-AS 模型 |
| --- | --- | --- | --- |
| 均衡的市场 | 产品市场 | 产品市场＋货币市场 | 产品、货币、劳动市场 |
| 利率 | 不考虑 | 考虑 | 考虑 |
| 价格水平 | 不考虑 | 不考虑 | 考虑 |
| 视角 | 需求方面（产出自动等于需求） | 需求方面 | 需求与供给两方面 |

共同点：三个模型都说明总产出的决定，推导都用到 $I=S$（总供给＝总需求）。

## 4.8 公式速查与自测

| 用途 | 公式 | 条件 |
| --- | --- | --- |
| 含价格的 LM | $r=-\dfrac{1}{h}\cdot\dfrac{M}{P}+\dfrac{k}{h}Y$ | $L=M/P$ |
| AD | $Y=\dfrac{h(\alpha+e)}{dk+h(1-\beta)}+\dfrac{d}{dk+h(1-\beta)}\cdot\dfrac{M}{P}$ | 两部门，IS＝LM |
| AD 斜率 | $\dfrac{dP}{dY}=-\left[k+(1-\beta)\dfrac{h}{d}\right]\dfrac{P^2}{M}$ | 同上 |
| 实际工资 | $w=W/P$ | |
| 短期生产函数 | $Y=f(N)$，$Y'>0$ | 技术、资本给定 |

1. 为什么 AD 向右下方倾斜？列出四种效应。
2. $h$、$d$ 怎样影响 AD 的斜率？
3. 价格变化与货币供给变化，分别引起沿 AD 移动还是 AD 移动？
4. 短期 AS 为什么呈"水平—倾斜—垂直"的形状？长期 AS 为什么垂直？
5. AS 左移会出现什么现象？主要原因是什么？
6. 有效需求决定模型、IS-LM 模型、AD-AS 模型的内在逻辑关系是什么？

??? question "自测答案"

    1. 价格上升使总需求减少：利率效应、财富效应、税负效应、进出口效应。
    2. $h$ 越小、$d$ 越大，AD 越平缓，产出对价格变动越敏感。
    3. 价格变化引起沿 AD 移动；价格不变时货币供给增加使 LM 右移，AD 右移。
    4. 短期货币工资只升不降：低价格段工资无法下调，产出可在价格几乎不变时增加；中间段价格上升降低实际工资、增加就业；到 $Y_f$ 后劳动充分就业，产出不再增加。长期货币工资完全伸缩，实际工资与就业不随价格变动，产出保持 $Y_f$。
    5. 产出下降而价格上升，即滞胀；主要原因是劳动力、资源等生产要素价格上升。
    6. 三者都以 $I=S$ 为基础：有效需求决定模型只看产品市场；IS-LM 加入货币市场和利率；AD-AS 再加入劳动市场和价格水平，并从需求、供给两方面说明产出决定。
