# 宏观经济学

宏观经济学研究总产出、利率、价格水平、失业与通货膨胀，以及它们之间的关系。

## 章节导览

| 章节 | 内容 |
| --- | --- |
| [第 1 章 总产出的核算](01-总产出的核算.md) | GDP 核算边界、三种核算方法、收入指标换算、储蓄与投资恒等式、名义与实际 GDP |
| [第 2 章 简单国民收入决定原理](02-简单国民收入决定原理.md) | 消费与储蓄、投资与净出口、均衡收入、乘数、财政政策及开放经济扩展 |
| [第 3 章 产品市场与货币市场均衡](03-产品市场与货币市场均衡.md) | IS、货币供求、LM、共同均衡、挤出效应与财政货币政策配合 |
| [第 4 章 总需求与总供给模型](04-总需求与总供给模型.md) | AD 的推导、斜率与移动，短期与长期 AS，AD-AS 均衡变动，三个模型的关系 |
| [第 5 章 失业与通货膨胀](05-失业与通货膨胀.md) | 失业的衡量、分类与成因，奥肯定律，通胀的衡量、类型、成因与效应，菲利普斯曲线，通缩与滞胀 |
| [第 6 章 经济周期](06-经济周期.md) | 周期的阶段与衡量（PMI、克强指数）、周期类型、早期周期理论、乘数-加速数模型、实际经济周期理论、中国的经济周期 |

后续章节讨论经济增长、开放经济与宏观经济政策。
