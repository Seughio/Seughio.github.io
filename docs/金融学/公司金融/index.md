# 公司金融

《公司金融》讲的是企业如何做三类财务决策：投资哪些长期项目（资本预算）、用什么方式融资（资本结构），以及如何管理日常运营资金（营运资本管理）。课程使用英文课件，本笔记根据第 1–7 讲课件整理为中文复习笔记，保留定义、公式及其适用条件、典型例题和易错点，专有名词首次出现时附英文。

## 知识主线

七讲是一条从“目标”到“风险”的链条：

1. **目标与制度**（第 1 讲）：财务管理的目标是最大化现有股东权益的价值，代理问题需要激励与公司控制机制来缓解。
2. **读懂报表**（第 2–3 讲）：决策看的是现金流而不是会计利润；比率分析和杜邦分解用来诊断企业，销售百分比法用来做财务规划。
3. **估值工具**（第 4 讲）：一切估值都是把现金流折到同一时点，这是后面所有折现方法的基础。
4. **资本预算**（第 5–6 讲）：先确定用什么准则接受项目（以 NPV 为首要准则），再确定项目现金流怎么算（只计增量现金流）。
5. **风险与弹性**（第 7 讲）：NPV 只是估计值，需要分析它对假设的敏感程度，并把管理弹性（实物期权）的价值计入。
