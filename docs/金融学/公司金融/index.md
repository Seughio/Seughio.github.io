# 公司金融

《公司金融》讲企业如何做三类财务决策：投资哪些长期项目（资本预算）、用什么方式融资（资本结构），以及如何管理日常运营资金（营运资本管理）。本笔记依据第 1–7 讲课程讲义整理，包括定义、公式及适用条件、例题和易错点，专有名词首次出现时附英文。

例题与数据参考课程讲义及 Ross、Westerfield、Jaffe《公司理财》（Corporate Finance），仅供学习交流。

## 知识主线

1. **目标与制度**（第 1 讲）：财务管理的目标是最大化现有股东权益的价值，代理问题需要激励与治理机制来缓解。
2. **读懂报表**（第 2–3 讲）：决策看现金流而不是会计利润；用比率分析和杜邦分解诊断企业，用销售百分比法做财务计划。
3. **估值工具**（第 4 讲）：一切估值都是把现金流折到同一时点。
4. **资本预算**（第 5–6 讲）：先确定接受项目的准则（以 NPV 为准），再确定项目现金流怎么算（只计增量现金流）。
5. **风险与弹性**（第 7 讲）：NPV 只是估计值，要分析它对假设的敏感程度，并计入实物期权的价值。

!!! tip "复习建议"

    考前可以先看每讲的「公式速查」「易错」和末尾的自测；计算题集中在第 4–7 讲。
